# PurrDash ????

**PurrDash** is a fast-paced 2D Endless Runner built in Unity. Players control an adventurous little cat running endlessly through a dynamic environment, dodging pesky mouse obstacles, and collecting power-ups to achieve the highest score!

## ?? Gameplay Features
- **Endless Runner Mechanics:** Continuous side-scrolling action with continuous running and jumping mechanics.
- **Power-Ups & Items:**
  - ?? **Tuna Can:** Grants 5 seconds of invincibility.
  - ?? **Heart:** Adds 1 extra life.
  - ?? **Coins:** Collectible items to gather along the run.
- **Obstacles:** Watch out for the cheeky mice blocking your path!
- **Dynamic Audio & UI:** Fully configurable sound effects and background music with a dedicated AudioMixer settings menu.

## ??? Controls
- **Spacebar:** Jump
- **ESC:** Pause / Main Menu Navigation
